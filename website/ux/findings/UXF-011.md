# UXF-011: the facts a reader came for are in the smallest type

Body prose is 14 px or more and readable in both themes. The values a reader looks up are not: the
status of a capability is a 10.4 px uppercase chip, the CLI's option names and defaults are
12.7 px, every command to copy is 13.1 px, and most of the landing page's text (the shipped and
planned strip) is 13.3 px. At 390 px these are the lines a reader zooms to read.

Sessions: all 48 gating page checks (the chips on landing, Status and 5 docs pages; tables
on 9 pages; code blocks on 6).

One line: raise the theme's small type tokens for chips, table cells and code to 14 px.

Cost M: type tokens in the shared theme; every page reflows, so the shots move.

Closed in R-01 (C5): a local override in `website/src/css/custom.css` sets table cells, code blocks, status chips and the landing status strip to 14 px. The shared `@beyond10x/docs-system` type scale is unchanged and should take the override over. Red on the R-01 site, green after.
