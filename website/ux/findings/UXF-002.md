# UXF-002: the theme toggle hides in the menu on a phone

Below Docusaurus's 997 px breakpoint the navbar keeps the logo and the menu button; the colour
mode toggle moves into the drawer, two actions away (open the menu, then the toggle). A reader
at night on a phone cannot see that a dark theme exists.

Cost S: CSS in `website/src/css/custom.css` shows the navbar's own toggle below the breakpoint.
