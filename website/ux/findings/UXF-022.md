# UXF-022: the request-log size is reachable only by luck of layout

The sidebar link `run --observe` lands on the `--observe` row. The answer is the next row,
`--observe-requests`. It was in view at 1280x800 in R-02 and is not in R-03, because three new
rows widened the flag column. The reader then searches "request records" and lands on the Observe
page's request-log section, which gave neither the number nor a link to the flag.

Fix: the Observe section states the default (256) and links
`../reference/cli.md#run--observe-requests`, so the search path ends on the row whatever the
table's layout.

Cost S: one sentence in `docs/concepts/observe.md`.
