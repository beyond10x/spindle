# UXF-010: file paths take the phone's first screen

Every docs page header lists the source files the page was written from (`crates/...rs`, up to
11 paths). It is provenance and it is useful, but on a phone it sits between the title and the
first sentence: on Observe the reader scrolls before reading one word of the page. The list is
in the same spot on every page, so it is also the most repeated text a reader skips.

Sessions: all 390x844 page checks of the 9 docs pages with a header (18 of 24); every play at
390x844 that lands on a concept page (http, observe, environment).

One line: fold the source list into a one-line "Sources (n)" disclosure below the lead.

Cost S: one component of the shared theme's doc header.
