# UXF-005: `run --observe` is findable only by someone who already opened the CLI reference

The answer is the `--observe` row of the `run` options in the generated CLI reference
(`GET /__spindle/requests`, `GET /__spindle/metrics`). The Observe concept page, which a reader
with the word "observe" opens first, covers the counters, telemetry, the observe API and the
control process (`deploy`), and does not name `run --observe`.

the CLI reference. Not chosen: a sentence on the Observe page (a prose edit to a page with pending edits
