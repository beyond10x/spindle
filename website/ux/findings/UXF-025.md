# UXF-025: the page's table of contents is the last thing Tab reaches

At 1280 px the "On this page" list sits beside the article at the top of the screen, and a
pointer reader clicks "Build" in one action. A keyboard reader gets there only after every
focusable element of the article: heading anchors, links, each code block (focusable for
scrolling) and the copy button that each one shows on focus. On Getting started that is 75 Tabs
for what the pointer does in one click, and longer pages cost more.

Sessions: install 1280x800 keyboard, both themes (86 Tabs). The other tasks reach their answer at
1280x800 by the search or the sidebar and do not pass the list.

One line: add a skip link to "On this page" after the skip to content, or put the list before
the article in the DOM at desktop width.

Cost M: the shared theme's doc layout.
