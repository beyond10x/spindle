# UXF-006: the release state is at the bottom of the longest page

A reader who asks "is it released, which version?" opens Status (the only word that fits), which
lists capabilities, not releases. The changelog is linked only from the footer, so the reader
scrolls the whole Status page (2791 words) to reach it.

Cost S: a navigation link to the changelog. Not in the R-00 change set (priority 0.2, below the
five chosen).
