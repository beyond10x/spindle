# UXF-001: the site has no search

The navbar holds Documentation, Getting started, Rally, CLI, Status, GitHub and the theme toggle;
no search field or button exists at any width. A reader with a term the navigation does not carry
("HTTP", "--observe", "version") can only scan and scroll: the screen-only reader needed 19
actions and did not reach the HTTP answer, 12 without reaching `run --observe`, and 26 for the
release state.

Docusaurus has no search without a plugin or a hosted index. Adding one is an interaction change:
it is the R-00 design decision (`rounds/R-00/decision.md`), not built in R-00.

Cost M.

Closed in R-01 (C1, decision answered yes, default A): `@easyops-cn/docusaurus-search-local` 0.55.3, a local index built with the site; on a phone the field sits in the navbar's flow beside the theme toggle. The asset ran red on the R-01 site as measured (`.out/R-01-build`) and green after; the gate-2 "search" mark is removed from `known-failing.json`.
