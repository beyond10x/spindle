# UXF-019: the one desktop table that does not fit is the one readers come for

UXF-009 is the phone case of every reference table. At 1280 px only one table overflows, and it is
the `run` options table: its option names (`--observe-requests <OBSERVE_REQUESTS>`) and the near
empty Required and Default columns take 415 px, so the meaning column runs 133 px past the
article. Each line of each meaning is cut at the right edge; the reader scrolls the table sideways
row by row, or reads half-sentences. The "More columns: swipe horizontally" line under the table is
the only cue on a desktop.

Sessions: the 4 page checks of reference-cli at 1280x800; observe, topology and request-log-size
at 1280x800, 12 plays, which land on rows of this table.

One line: let option names wrap and narrow the Required and Default columns so the table fits 703 px.

Cost S: table CSS for the CLI reference's option tables in `website/src/css/custom.css`.

## Closed in R-02
