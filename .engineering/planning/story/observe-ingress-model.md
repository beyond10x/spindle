# The request log, metric families and topology are specified in spindle.observe

## Outcome

Every noun the reserved routes answer has its home in `spindle.observe` before any code serves it:
`RequestClass`, `OperationKind`, `AnswerSource`, `ExternalAnswer`, `RequestRecord`,
`RequestTotals`, `RequestLog` (the answer of `/__spindle/requests`, format `spindle-requests/1`),
`MetricKind`, `MetricFamily`, `MetricFamilies` (the families `/__spindle/metrics` exposes),
and `NodeKind`, `EdgeKind`, `TopologyNode`, `StatusCount`, `SourceCount`, `EdgeTraffic`,
`TopologyEdge`, `Topology` (the answer of `/__spindle/topology`, format `spindle-topology/1`).
They are projected to JSON Schema, to Rust in `spindle-observe-api` and to TypeScript in
`ui/src/api/generated`, and drift-checked as the existing observe answers are. This is the
contract a consumer's banner and a host redrawing the graph read.

The proposed domain is `docs/design/proposals/observe-ingress.yaml`, a complete file that
replaces the repository's. `ess specify validate` accepts it with the 0.87.0 toolchain.

## Acceptance

- `check:the_observe_domain_validates` passes with `spindle.observe.RequestLog`,
  `spindle.observe.MetricFamilies` and `spindle.observe.Topology` added to `OBSERVE_ROOTS`.
- `check:the_generated_types_have_no_drift` passes: schema, Rust and TypeScript regenerated by
  `task generate:observe` and committed.
- `check:every_fixture_answer_validates_against_its_schema` covers
  `ess/fixtures/observe/requests/*.json`, `ess/fixtures/observe/metrics/families.json` and
  `ess/fixtures/observe/topology/*.json`, each valid; a fixture with an unknown `class` is
  refused (checked by hand at draft time: `"lost" is not one of "served", "refused" or 4 other
  candidates`).
- `a request log fixture reads as RequestLog` and `a topology fixture reads as Topology`
  (vitest, `ui/src/api/types.test.ts`): the fixture parses through the generated type guards.
- `docs/design/observe.md` gets a section for the reserved routes and § 7 points to it; § 9's
  open question on the home of the API nouns is answered for these nouns.
